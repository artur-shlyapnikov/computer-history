# Contributing

Bug reports and focused pull requests are welcome. Describe the expected and
actual behavior, include your operating system and tool versions, and use a
minimal reproduction with synthetic data.

Follow the setup instructions in [README.md](README.md). Run `just --list` to see
available development commands and `just check` before submitting a change. Some
platform or integration checks require extra tools or permissions described in
the README. State which checks you ran and any limitations in your pull request.

Keep changes focused, add regression coverage for behavior changes, and update
user-facing documentation when commands or behavior change. Do not commit local
credentials, recordings, generated reports, dependency caches, or build outputs.
