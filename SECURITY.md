# Security

This project is under active development. Security fixes target the latest code
on `main`; older snapshots do not have a maintenance guarantee.

Report vulnerabilities privately through GitHub **Security → Report a
vulnerability** when the repository has private reporting enabled. Otherwise,
open an issue requesting a private contact channel without publishing exploit
details, credentials, recordings, personal data, or private project files.

Include the affected version, operating system, expected impact, and a minimal
reproduction using synthetic data. Never attach live credentials or private data.
